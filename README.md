# Тёмные текстуры для Minecraft

Проект по информатике. Автор: Швецов Артем Игоревич, 10 «И», школа № 2100.

Сайт, на котором можно скачать ресурспаки в стиле Dark Fantasy для Minecraft 1.20.1.

## Что внутри

- `index.html` — главная страница
- `textures.html` — каталог текстур с поиском
- `all.html` — все текстуры на одной странице и общий пак одним файлом
- `contacts.html` — контакты
- `style.css` — оформление всех страниц
- `search.js` — поиск по карточкам
- `packs/` — готовые ресурспаки (zip)
- `images/` — баннер, фон, иконка и картинки текстур (всё нарисовано программой)
- `generator/make_packs.py` — программа на Python, которая рисует текстуры и собирает паки

## Как открыть сайт

Просто открыть `index.html` в браузере. Сервер и база данных не нужны.

## Как заново сделать текстуры

```
pip install pillow
cd generator
python make_packs.py
```
